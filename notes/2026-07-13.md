# 2026-07-13 — Project kickoff

## Context
Internship at SciLifeLab, Lundeberg Lab. Deep learning project on spatial
transcriptomics: either (a) filling gaps in 3D between tissue slices, or
(b) filling in damaged tissue regions within a slice. Goal: build a general,
swappable architecture that can host different generative model backbones,
then apply it to real lab-relevant data.

## Literature scoping (first pass — see docs/literature_review.md for full list)
- Found a very close prior-art match: **Mimyr** (bioRxiv, Nov 2025) —
  generative reconstruction of missing tissue via
  location→cell-type→expression decomposition, diffusion-based. Read this
  first, in full.
- **isoST** (bioRxiv, Aug 2025) — alternative continuous-field (SDE) approach
  to the inter-slice problem specifically.
- Slice alignment (PASTE, STAligner, STitch3D, Spa3D, SPACEL, SpaBatch) is a
  likely prerequisite step for the 3D task, separate from generation itself.
- No existing FID-style distributional fidelity metric for ST found — likely
  a genuine gap and a good candidate for the "develop a new metric" part of
  the project. Plan sketched in docs/metrics_notes.md.
- Candidate public datasets shortlisted in docs/dataset_notes.md — mouse
  organogenesis (MOSTA, Stereo-seq) and whole mouse brain atlas look like the
  strongest public pilots; STARmap PLUS CNS atlas is genuinely volumetric and
  could serve as a "gold standard" to synthetically down-sample for training/
  validation.

## Addendum — literature fact-check pass (same day)
Ran every citation in docs/literature_review.md, docs/dataset_notes.md, and
docs/metrics_notes.md against live web searches before trusting them.
Outcome: nothing was fully fabricated, but several entries had real errors —
worth remembering when reading the docs:
- **isoST** evaluated on mouse brain/embryo/kidney/spinal cord, not "spleen."
- **"STDIFFUSION"** as a named bioRxiv paper doesn't exist — the closest real
  thing is an OpenReview workshop submission ("stDiffusion"), much weaker
  evidence than a peer-reviewed preprint. Don't cite it as if it were one.
- **C2-STi**: the ST/histology roles were backwards in the first draft — it
  interpolates missing *ST* slices using histology as the auxiliary input,
  not the other way around.
- **SpatialZ** is a real generative framework (Nature Methods 2025, scales to
  a 38M-cell mouse brain atlas) — not a "lookup-based" method as first noted;
  possibly a stronger baseline than originally assumed, worth re-reading.
- **X-Pression** actually reconstructs from micro-CT + a single Visium
  section, not from multiple ST slices — less directly applicable to the
  inter-slice task than assumed.
- **STAligner** is graph-attention/domain-based, not landmark-based (that's a
  different, similarly-named tool, STalign).
- A Fréchet-distance metric for generative single-cell (non-spatial) models
  already exists — **scFID** (bioRxiv 2025.04.14.648850). No spatial-specific
  version exists yet, so the "new metric" plan still stands, but cite scFID
  as prior art rather than claiming the recipe itself is novel.
- Lundeberg-lab citations were all real; one journal name was wrong (Li et
  al. breast cancer paper is in *npj Precision Oncology*, not "Nature
  Precision Oncology").
- All 7 candidate datasets in dataset_notes.md checked out accurately; only
  soft spot is the "aging atlas" STOmics dataset ID, which wasn't
  independently confirmed.
