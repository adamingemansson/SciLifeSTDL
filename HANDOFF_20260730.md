## Scientific problem

Model a genuinely broken/missing spatial-transcriptomics tissue region. For a
query hole, both its measured GEX and its overlapping H&E pixels must be absent
from the input. The model may use all available surrounding GEX, local and full
hole-boundary geometry, visible H&E context, and whole-slide context to predict
all genes in the missing spots. The purpose is not ordinary spot interpolation:
the model should learn tissue-conditioned spatial fields and gradients, use the
opposite side of a hole, and eventually support stochastic generation.

Core biological assumptions:

- Whole-slide H&E gives tissue type/global morphology.
- Regional H&E and nearby observed spots describe the local tissue state.
- The complete boundary around a hole describes how expression enters it from
  every side; proximity matters, but context is not limited to a tiny nearest-
  neighbour set.
- Coordinates describe relative geometry only. They are centered and normalized
  by sample spot spacing, never used as absolute sample identifiers.
- GigaPath and gene encoders provide representations; the trainable spatial
  transformer/transport system must learn the H&E/GEX relationship.
- Harmonic interpolation is a required strong baseline/ablation, not ground
  truth and not something every learned model should secretly inherit.

## Gen3 architectures now being tested

Shared core: 512 hidden dimensions, 8 heads, 4 transformer blocks, relative
geometry, query tokens, per-query local observed context, full boundary rings,
and a gene-aware transport head predicting all 17,189 genes from observed GEX.
The transport head preserves observed gene values as candidates and learns
gene/query-dependent mixing. All arms use the same masks, initialization where
parameters are shared, optimizer, loss, seed, and data.

1. **Architecture 1 — anchor-free full-boundary field.** Weighted trainable GEX
   encoder + precomputed spot-level GigaPath + spatial transformer/transport.
   No harmonic anchor and no regional/global WSI branch.
2. **Architecture 2 — harmonic-residual full-boundary field.** Architecture 1
   plus an explicit non-learned harmonic anchor/blend. This isolates whether the
   learned correction improves a strong spatial prior.
3. **Architecture 3 — hierarchical slide-boundary field.** Anchor-free, with
   all-observed-GEX inducing tokens, regional dense-WSI GigaPath tokens, and a
   mask-aware frozen GigaPath LongNet global slide vector. This is the complete
   deterministic architecture matching the intended biology.
4. **Architecture 4 — hierarchical residual flow.** The exact trained/frozen
   Architecture 3 conditioner supplies the deterministic mean; a conditional
   flow generates uncertainty/residual variation in a rank-64 training-only
   gene basis. It is generative for residuals, not a from-scratch generator of
   the full expression vector.

Architecture 4 cannot be trained concurrently with Architecture 3. Select
Architecture 3 using validation only, fit the rank-64 residual basis from
training residuals only, then resolve and start Architecture 4 against that
exact immutable Architecture 3 bundle.

## Evaluation and decision rule

Train on all genes. Primary results remain full-panel PCC and RMSE; do not hide
poor full-gene performance behind a favourable small panel. Always also report:

- Train-log1p-variance top 50 and top 200 genes, derived dynamically from the
  training split (never a held-out or fixed hand-selected HVG panel).
- Any named benchmark panel that actually overlaps the frozen gene panel.
- Nonzero AUC.
- Per-mask-stratum and per-item results.
- Per-sample and patient-level aggregation with 95% t-based confidence intervals.
- Matched training-mean, nearest-neighbour, and harmonic baselines, including
  paired model-minus-baseline deltas and confidence intervals.
- Architecture 4 predictive spread/calibration when it exists.
- ST-FID/MMD only as secondary diagnostics, never primary selection metrics.

Select checkpoints and all design decisions using validation only. A learned
model is interesting only if it demonstrates real learning and improves on the
matched baselines, especially harmonic, on held-out patients. Run the locked
test split once after selection using `--allow-test`.

Older Wave 4–7/INT and Gen2 numbers are useful diagnostics but are not directly
comparable to this run. They used different sample scopes, masks, evaluation
semantics, or code predating critical leakage/coordinate/cache fixes. Same-sample
harmonic results around PCC 0.5 and held-out results near zero demonstrated how
large this distinction is. The present 56-sample Gen3 run is intended to be the
first reliable multiorgan comparison.

### Gen5 intent

The same four conditioning arms, but replace rank-64 residual flow with a shared

the route toward generating the entire gene-expression vector rather than only
residual variation around a deterministic mean. First report the autoencoder's
